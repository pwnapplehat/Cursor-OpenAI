Configuration

Every configurable option on this gateway - nothing is left to a config file only. Changes apply live; a few need a restart, which you can also trigger right here.

Cursor API key
The credential this gateway uses to talk to Cursor on your behalf.
Key mode
Whether every client shares this one key, or supplies its own.
Runtime
Where Cursor agents actually execute.
Agent conversation mode
"Plan" only reasons/plans; it never edits files or runs commands.
Default model
Used whenever a client omits "model" or requests one you don't have access to. Browse the full catalog under Models.
Sessions
How multi-turn conversations reuse a live Cursor agent instead of replaying history.
Session idle timeout
Minutes of inactivity before a cached agent is evicted.
Max cached agents
Oldest-used sessions are evicted first once this limit is reached.
Reasoning
Stream the model's chain-of-thought as an OpenAI-style reasoning_content field.
Tool-calling bridge
Translates OpenAI tools[] function-calling into Cursor's native tool system (local runtime only).
Tool bridge mode
"Hold" keeps one Cursor run alive across a whole tool loop (one metered request, captures parallel calls). "Cancel" is the legacy one-run-per-step behavior.
Tool result timeout
Hold mode only: seconds a held run waits for the client's tool result before it's torn down (freeing the agent and its concurrency slot).
Max concurrent runs
Total Cursor agent runs allowed in flight at once, across all clients.
Request timeout
Seconds before an in-progress run is cancelled and reported as a timeout.
Rate limit — max requests
Per client (by API key/IP), per window.
Rate limit window
Seconds per window. Needs a restart to take effect - use the button below once you save.
Max request body size (MB)
1–1024. Oversized bodies get HTTP 413 (clients like Hermes compress their history and continue). Needs a restart to take effect.
